# 裱花蛋糕设计与效果预览工作台

浏览器内运行的定制蛋糕设计系统：TypeScript + WebGL2，SDF 光线步进自研着色器，
数据本地存 IndexedDB，零运行时依赖。

## 启动

```bash
pnpm install
pnpm dev
```

类型检查与生产构建：

```bash
pnpm build
```

测试（Node 24 原生 TypeScript 支持，无需安装依赖）：

```bash
pnpm test
```

## 页面

| 页面 | 能力 |
| --- | --- |
| 订单列表 | 客户、日期、人数、预算录入；一个订单挂多个设计方案 |
| 蛋糕胚 | 圆 / 方 / 心三种形状，多层堆叠，层高直径可调，按人数推荐尺寸 |
| 裱花编辑 | 沿路径挤奶油，花嘴截面决定形状，速度与压力影响粗细；玫瑰、贝壳边、糖珠边、星星边、侧面环带一键生成 |
| 装饰件 | 草莓、蓝莓、巧克力片、糖珠、数字蜡烛，可拖拽摆放、旋转、缩放 |
| 效果预览 | 店内 / 婚礼现场两种灯光，导出客户效果图 PNG，打印裱花师制作单 |
| 设置 | 三种材质密度、目标帧率、渲染缩放、IndexedDB 数据导入导出 |

订单页点「载入三个测试方案」会播种：三层婚礼蛋糕、镜面淋面慕斯、数字生日蛋糕。

## 渲染架构

- 每条挤花路径在 CPU 离散为管段（端点、半径、花嘴截面、颜色），打包进 RGBA32F 数据纹理
- GPU 着色器用 48³ 非立方空间网格 + Amanatides-Woo DDA 遍历光线穿过的格子，
  只对格内管段做 SDF 求交，避免每光线遍历全部管段
- 蛋糕胚（圆柱 / 圆角盒 / 心形拉伸）与装饰件走常规 SDF 步进，管段走网格步进，两路取最近
- 材质：奶油（FBM 颗粒法线扰动）、翻糖（哑光）、镜面淋面（环境反射 + 程序化滴落边）
- 帧率低于目标 85% 时自动降渲染分辨率（下限 50%），恢复后自动回升

## 两个硬指标

### 帧率

管段规模与网格峰值在 `tests/scenarios.test.ts` 中断言；裱花页内置
「百朵玫瑰压力测试」按钮，视口 HUD 实时显示 FPS 与自适应缩放。

### 体积对账误差 < 2%

每条路径体积用解析公式 `截面积系数 × ∫r(t)²dt` 计算，制作单与用料统计
共用同一份 `pathVolume` 结果。`tests/piping_volume.test.ts` 分别对：

- 等径直圆管与 πr²L 解析解对账
- 变半径路径与积分解析解对账
- 三个测试方案的统计总量与逐路径逐条累加对账
- 120 朵玫瑰、上千管段的压力场景对账

全部断言误差上限 2%，当前实测误差为浮点级（远小于 0.1%）。
