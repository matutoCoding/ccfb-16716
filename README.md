# Gateau Studio · 裱花蛋糕设计与效果预览系统

一个纯浏览器运行的定制蛋糕设计工具：TypeScript + 原生 WebGL2，蛋糕/材质使用 SDF 光线步进 Shader，挤花路径使用花嘴截面扫掠网格，订单、方案和自动保存数据存 IndexedDB。

## 启动

```bash
npm install
npm run dev
```

打开终端输出的 `http://127.0.0.1:5173/`。

生产构建：

```bash
npm run build
npm run preview
```

## 已实现页面

- **订单列表**：客户、电话、场合、日期、人数、预算、状态、备注；一个订单可创建/复制多个方案。
- **蛋糕胚**：圆形、方形、心形；最多多层叠加；每层直径/边长、高度、XY 偏移可调；按人数和场合推荐尺寸。
- **裱花编辑**：
  - 顶面按住拖拽沿自由路径挤奶油；
  - 圆口、星星、法式、玫瑰花瓣、叶子等花嘴，截面由轮廓多边形生成；
  - 压力和挤速共同决定截面积，打发程度影响颜色；
  - 玫瑰、星星花一键点击放置，贝壳边/圆珠边一键沿轮廓生成；
  - 路径可显示/隐藏、排序、删除；
  - 每行路径独立统计 ml/g，并与总用量逐行累加。
- **装饰件**：草莓、蓝莓、樱桃、巧克力片、巧克力豆、糖珠、0–9 数字蜡烛；支持点击摆放、XYZ 定位、旋转、缩放、改色、复制和删除。
- **效果预览**：拖拽环绕、滚轮缩放、自动旋转、复位；店内自然光/婚礼暖光；导出带订单与规格信息的客户 PNG。
- **设置**：渲染分辨率、DPR 上限、FPS、阴影、颗粒、自动保存、材料密度、JSON 导入导出、清空 IndexedDB、浏览器内自检。
- **制作单打印**：每层胚体、抹面/翻糖/淋面、裱花奶油克数、花嘴型号与截面积、按 sequence 排序的裱花顺序、压力/速度/体积；可直接打印或在打印对话框另存 PDF。

## 渲染方案与性能

- 蛋糕体、纸板、地面和镜面淋面滴落边在同一个 WebGL2 fragment shader 中用 SDF + ray marching 计算。
- 奶油材质使用 3D value noise 做细微颜色和法线颗粒；翻糖更平滑；淋面使用低粗糙度、clearcoat/Fresnel 和柔光灯箱高光。
- 每条挤花路径按采样点建立平行移动坐标架，将真实花嘴截面轮廓扫掠成管；所有路径合并到单个网格，仅一次 draw call。
- 装饰件合并为普通网格，数字蜡烛使用 Canvas 生成的 5×2 数字图集。
- FPS 持续低于 30 两拍后会自动把渲染分辨率系数下调 12%，最低约 62%；持续高帧后缓慢恢复。也可在设置中手动降到 70% 左右。

本机用系统 Chrome + ANGLE/D3D11 跑 `npm run verify:browser`：三层婚礼方案再生成 120 朵压测花后共 **149 朵玫瑰/星星、155 条路径、约 44 万三角面**，脚本模拟连续拖拽时 FPS 采样为 **161–166 FPS**，控制台无 WebGL/Shader 错误。SwiftShader 软件渲染会明显更慢，不代表带 GPU/核显的店里电脑；无独显设备可使用自适应分辨率或在设置中手动降低渲染比例。

## 体积统计口径

体积不是只按“朵数估算”，而是对每条路径做截面积分：

```text
V = Σ 段长 × (Aᵢ + Aᵢ₊₁) / 2
Aᵢ = nozzle.areaCm2 × scaleᵢ²
scale 由压力/速度形成的截面积比开平方得到
```

闭合贝壳/圆珠边会把首尾段也计入。花嘴面积由截面轮廓多边形的鞋带公式精确计算。UI 中所有路径行之和与总奶油体积使用同一组结果再次累加，因此口径一致。

`npm test` 包含：

- 直线路径体积 = 花嘴面积 × 长度；
- 扫掠网格有符号体积与积分体积误差 < 2%；
- 压力/速度变化和闭合路径；
- UI 行体积累加 = 总体积；
- 三套业务方案和 120 朵压测数据；
- 人数推荐尺寸。

最近一次结果：9/9 测试通过。设置页中的“运行自检”也会在浏览器里执行同一组核心检查和 IndexedDB 读写。

1. **GD-W261218 · 三层婚礼蛋糕**：30/23/15cm，翻糖 + 奶油，双层贝壳/圆珠围边，29 朵定位玫瑰；另有“方案 B · 香槟轻奢”验证同一订单多方案。

3. **GD-B261128 · 数字生日蛋糕**：28cm 方形奶油蛋糕，网格星星花、贝壳/圆珠边、彩色糖珠和数字蜡烛 3、0。

详细验收记录见 [`docs/test-plan.md`](docs/test-plan.md)。

## 浏览器自动验收脚本

这些脚本使用 `playwright-core` 驱动本机 Chrome；如 Chrome 不在默认路径，设置 `CHROME_PATH` 或修改脚本中的 `executablePath`。

```bash
npm run verify:browser     # 页面流程、120 朵压测、拖拽 FPS、设置自检、截图到 reports/
npm run verify:scenarios   # 三套方案截图
npm run verify:outputs     # PNG 导出和制作单内容检查
```

## 代码结构

```text
src/
  data/          花嘴、色卡、默认对象、三套播种方案
  lib/           几何/推荐尺寸、路径采样、体积、材料统计、滴落、IndexedDB、自检
  render/        WebGL2 Renderer、GLSL shaders、扫掠网格/装饰几何、场景合并
  state/         全局 store + IndexedDB 防抖保存
  ui/            DOM helper、Viewport
  pages/         订单、蛋糕胚、裱花、装饰、预览、设置
  tests/         Vitest 体积与方案测试
scripts/         Playwright 验收脚本
```
