## 3. 浏览器端到端验收

脚本：

```bash
npm run verify:browser
npm run verify:outputs
npm run verify:scenarios
```

脚本使用 Playwright + 本机 Chrome，自动执行：

- 订单页渲染和 IndexedDB 播种；
- 进入蛋糕胚页并初始化 WebGL2；
- 进入裱花页，点击「＋120 朵压测」；
- 在 canvas 中央模拟连续拖拽旋转；
- 读取 FPS、三角面和体积面板；
- 进入装饰页、预览页、设置页并运行自检；
- 导出客户 PNG；
- 生成制作单并检查标题、花嘴、裱花顺序和 ml 体积；
- 分别截图婚礼、慕斯、数字生日场景。

截图输出到 `reports/`。

### 最近一次性能结果

场景：T1 三层婚礼方案 + 120 朵额外压测花。

```text
花朵/星星数量：149 朵
路径数量：155 条
网格规模：约 440k 三角面
连续拖拽 FPS：161–166 FPS
控制台 Shader/WebGL 错误：0
```

运行环境：Windows + 本机 Google Chrome，Playwright/`playwright-core`，硬件 ANGLE/D3D11 路径。该结果显著高于“上百朵挤花旋转 ≥30 FPS”的验收线。

说明：使用 `--use-angle=swiftshader` 强制软件渲染时，同一场景约为 3–5 FPS；这是 CPU 模拟 WebGL 的结果，不代表普通带 GPU/核显的营业电脑。Renderer 已实现低于 30 FPS 自动降低渲染分辨率；门店低端设备也可在设置中手动使用 70% 渲染比例和 DPR 1。

## 4. 用料一致性人工核对方法

1. 打开任意方案的「裱花编辑」；
2. 查看右侧每条路径的 ml 数；
3. 面板绿色提示显示：
   `每行体积累加 = 总计：X / X ml，偏差 0.000%`；
4. 点击「打印 / 导出制作单」，表格中的每条路径体积与右侧列表使用同一个 `listPipingVolumes()` 结果；
5. 打印单合计奶油克重 = 合计 ml × 奶油密度（默认 1.08 g/ml，可在设置调整）。
